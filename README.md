# Zomato Restaurant Analytics Dashboard

## Project Overview
This project analyzes Zomato restaurant data using Microsoft Excel and presents insights through a dashboard, supported by a project report and presentation.

## Project Objectives
- Clean and organize restaurant data.
- Analyze data using Excel formulas and PivotTables.
- Create KPIs and visualizations.
- Present findings to support data-driven decisions.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas
- Data cleaning and visualization
- Microsoft PowerPoint
- Microsoft Word

## Project Files
- **Excel Dashboard:** Main workbook containing the dataset, analysis, and dashboard.
- **PowerPoint Presentation:** Summary of the project and its findings.
- **Project Report:** Detailed documentation of the analysis.

## Key Insights
Refer to the Excel workbook and project report for the findings and recommendations derived from the analysis.
